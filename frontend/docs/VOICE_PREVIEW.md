# Vercel 미리보기에서 음성 시작 테스트

## Vercel 설정

1. 외부 업체로 녹음 원본을 전송하는 미리보기입니다. 팀의 승인된 테스트 계정 및 가상의 문장만 사용하고, 미리보기 URL은 배포 보호로 팀에 제한합니다. 음성 동의 쿠키는 이용 동의 표시이며 미리보기 접근 인증이나 요청 제한이 아닙니다.
2. 아래 값은 **Preview 환경에만** 설정하고 재배포합니다. Production에는 이 모드가 켜지지 않습니다.

| 키 | 값 |
| --- | --- |
| `NEXT_PUBLIC_VOICE_ENABLED` | `1` |
| `NEXT_PUBLIC_VOICE_EXTERNAL_STT` | `1` |
| `VOICE_STT_PROVIDER` | `openai` |
| `VOICE_OPENAI_API_KEY` | 음성 테스트용 서버 전용 키 |
| `VOICE_CONSENT_SECRET` | 충분히 긴 임의의 서버 전용 비밀값 |
| `APP_URL` | 테스트에 실제 접속하는 미리보기 HTTPS 주소 |

로컬의 `dev.cmd`와 Whisper는 기존대로 동작합니다. Preview에서는 받아쓰기만 외부로 보내고 후속 질문 읽기에는 브라우저가 제공하는 로컬 한국어 음성을 사용합니다. 해당 음성이 없거나 브라우저가 자동 재생을 차단해도 문진과 텍스트 입력은 가능합니다.

## 실기기 확인

- 처음 방문하거나 새 대화로 시작 화면에 돌아왔을 때 첫 질문이 글자로 표시되고 자동으로 읽히지 않는지 확인합니다.
- 음성으로 대답하기를 누르기 전에는 마이크가 켜지지 않아야 합니다. 건강정보 동의와 외부 음성 안내 이후 테스트 문장 “기침이 나요”가 첫 답변으로 연결되는지 봅니다.
- 말이 끝난 시각, 받아쓴 텍스트가 보인 시각, 다음 문진 질문이 보인 시각을 각각 기록합니다. 자동 전송에는 3.5초의 수정·취소 시간이 붙고, 바로 보내려면 기존 전송 화살표를 누릅니다.
- 읽기 기본값 70%, 음소거, 음량 조절을 확인합니다. 기기에 한국어 음성이 없으면 후속 질문은 화면으로 확인합니다.
- 거절과 건너뛰기, 권한 거부에서 텍스트로 진행되는지 확인합니다.
