# Vercel 배포에서 음성 시작 테스트

## Vercel 설정

기본 STT는 OpenAI의 `gpt-transcribe`입니다. 문진 엔진과 같은 `OPENAI_API_KEY`를 사용합니다. 별도 키나 모델 환경변수는 필요하지 않습니다.

외부 업체로 녹음을 전송하므로 팀의 승인된 테스트 계정과 가상의 문장을 사용하고 미리보기 URL은 배포 보호로 제한합니다.

**동의는 건강정보 수집·이용 동의 하나로 받습니다(2026-11-25).** 따로 묻던 음성 전송 동의(동의 쿠키)는 없앴습니다. 상담 시작 때 보여 주는 건강정보 처리 안내(`health-consent.mjs`의 `careAiHealthNotice`, 버전 `care-openai-2`)의 항목에 "음성으로 답한 경우 녹음한 음성"이, 외부 처리에 "녹음을 미국 OpenAI 음성 인식으로 보내 글자로 바꿈(가리는 처리 없음, HearO는 저장하지 않음)"이 들어 있습니다. 브라우저는 음성 요청에 동의한 안내 버전(`x-health-consent`)을 붙이고, 서버는 지금 버전과 같을 때만 녹음을 보냅니다(`/api/care`가 OpenAI 전송 동의를 확인하는 방식과 같음). 안내가 바뀌어 버전이 오르면 이전 동의로는 보낼 수 없습니다.

다음 값은 사용할 배포 환경(Production 또는 Preview)에 설정하고 재배포합니다. 외부 STT는 배포 환경 구분 없이 설정과 사용자 동의에 따라 동작합니다.

| 키 | 값 |
| --- | --- |
| `NEXT_PUBLIC_VOICE_ENABLED` | `1` |
| `NEXT_PUBLIC_VOICE_EXTERNAL_STT` | `1` |
| `VOICE_STT_PROVIDER` | `openai` |
| `NEXT_PUBLIC_VOICE_STT_PROVIDER` | `openai` (서버와 동일하게 설정, 생략 시 openai) |
| `OPENAI_API_KEY` | 문진 엔진에도 사용하는 기존 OpenAI API 키, 서버 전용 |
| `APP_URL` | 실제 접속하는 배포 사이트의 HTTPS 주소(형식이 틀려도 앱이 멈추지는 않고 Vercel 배포 주소를 씀, `lib/app-origin.mjs`) |

기존 BAZE 배포에서는 두 제공자 값을 모두 `openai`로 바꾸고 재배포합니다. `NEXT_PUBLIC_` 값은 빌드에 반영되므로 환경변수 저장만으로는 적용되지 않습니다. `VOICE_OPENAI_API_KEY`는 더 이상 사용하지 않습니다. OpenAI만 쓰면 `VOICE_CONSENT_SECRET`도 필요 없습니다(BAZE의 결과 확인 토큰 서명에만 씀). 업체를 BAZE로 바꾸면 건강정보 처리 안내의 외부 처리 문구도 함께 바꾸고 버전을 올려야 합니다.

## OpenAI 처리 흐름

- 브라우저 녹음을 `/api/voice/stt`로 보내고 서버가 `OPENAI_API_KEY`로 OpenAI `/v1/audio/transcriptions`의 `gpt-transcribe`를 호출합니다.
- 키는 서버에서만 읽습니다. HearO는 녹음 파일을 저장하거나 로그에 남기지 않습니다.
- 키가 없으면 503, 동의 없는 요청이나 허용되지 않은 출처의 요청은 403, 음성 기능을 끈 경우에는 404로 거절합니다.
- 후속 질문 읽기에는 브라우저의 로컬 음성을 사용합니다. 로컬 음성이 없어도 문진과 텍스트 입력은 가능합니다.
- 로컬 `dev.cmd`와 Whisper 방식은 그대로 사용할 수 있습니다. 로컬에서 OpenAI를 시험하려면 위 외부 STT 설정과 기존 키를 `frontend/.env.local`에 설정하고 개발 서버를 다시 시작합니다.

## 선택 사항: BAZE 연결 유지

두 제공자 값을 `baze`로 설정하고 `BAZE_API_KEY`를 등록하면 기존 BAZE 경로를 사용할 수 있습니다. `BAZE_BASE_URL` 기본값은 `https://factchat-cloud.mindlogic.ai/v1/gateway`, `BAZE_STT_MODEL` 기본값은 `stt-async-v5`입니다. 모델 지원 여부는 업체에 확인합니다.

BAZE에서는 브라우저가 녹음을 16kHz·모노·16bit WAV로 변환합니다. 서버는 최대 30초의 WAV를 검사해 업로드한 후 최대 8초 기다립니다. 처리 중이면 서명된 토큰(`VOICE_CONSENT_SECRET`로 서명)을 반환하고 브라우저가 `/api/voice/stt-status`로 결과를 확인합니다. 업로드 횟수는 접속 주소별로 10분당 20회로 제한하며 서버 인스턴스마다 집계합니다. BAZE 변환 결과는 업체 서버에 1시간 보관 후 삭제되는 것으로 안내하며, 원본 보관 기간·처리 위치·학습 이용은 업체 확인 전입니다.

## 실기기 확인

- 첫 방문과 새 대화 시작 시 첫 질문이 글자로 표시되고 자동으로 읽히지 않는지 확인합니다.
- 음성으로 대답하기 전에는 마이크가 켜지지 않아야 합니다. 건강정보 수집·이용 동의 한 번 뒤에 바로 녹음이 시작되고(따로 음성 동의를 묻지 않음), 가상 문장 “기침이 나요”가 첫 답변으로 연결되는지 확인합니다.
- 말이 끝난 시각, 받아쓴 텍스트가 보인 시각, 다음 질문이 보인 시각을 기록합니다. 자동 전송에는 3.5초의 수정·취소 시간이 있고 전송 화살표로 바로 보낼 수 있습니다.
- 읽기 기본값 70%, 음소거, 음량 조절을 확인합니다. 로컬 음성이 없으면 질문을 화면으로 확인합니다.
- 동의 거절, 건너뛰기, 마이크 권한 거부 시 텍스트로 진행되는지 확인합니다.
