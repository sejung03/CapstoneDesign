# 다국어 화면

한국어(ko), 영어(en), 중국어 간체(zh), 베트남어(vi), 우즈베크어 라틴 문자(uz)를 지원합니다. 헤더의 언어 선택은 입력 초안을 유지하며 선택 언어를 브라우저에 저장합니다. 회원가입 화면도 같은 언어를 이어받습니다.

## 실행 중 번역 API 사용 없음

화면의 버튼·안내·오류·동의 항목·문진·응급 안내·내 정보·PDF 문구는 저장된 번역 파일에서 읽습니다. 화면 조회나 언어 변경 시 Gemini API를 호출하지 않습니다. Gemini 데모 화면과 API는 제거했습니다.

병원명·주소와 사용자가 직접 입력한 문장은 원문을 보존합니다. 지도 타일·외부 카카오 페이지·공식 영상 자막의 언어는 변경하지 않습니다. 카카오 지도·의료기관 검색 API는 별도로 사용합니다.

| 파일 | 역할 |
| --- | --- |
| `i18n.mjs` | 언어 목록, 문구 조회, 변수 치환, API 다국어 텍스트 검증 |
| `locales/source.json` | 영어 원문 키와 한국어 기준 문구 |
| `locales/zh.json`, `vi.json`, `uz.json` | 저장된 번역 |
| `copy.mjs` | 기존 화면의 의미 키를 공통 번역에 연결 |

새 번역은 기계번역 초안이므로 의료·응급·동의 문구는 공개 배포 전 해당 언어 사용자와 담당자의 의미 검수가 필요합니다.

## 개발 중 번역 파일 갱신

`scripts/translate-locales.mjs`와 `lib/openai-json.mjs`는 개발자가 고정 문구 번역을 갱신할 때만 쓰는 도구로 유지합니다. 앱에서는 호출하지 않습니다. 번역 모델은 OpenAI `gpt-6-luna`(11/23, 이전 Gemini)이고 `TRANSLATE_MODEL`로 바꿀 수 있습니다. 필요할 때만 서버 전용 `OPENAI_API_KEY`를 설정하고 직접 실행합니다.

```powershell
node --env-file=.env.local scripts/translate-locales.mjs
```

이 명령을 실행할 때만 Gemini API 사용량이 발생합니다. 사용자 정보나 상담 기록을 넣지 마세요. 기존 키는 자동 삭제하지 않았으며 사용하지 않으면 `.env.local`에서 제거해도 됩니다. `GEMINI_DEMO_ENABLED`는 더 이상 사용하지 않습니다.

## 확인

헤더에서 5개 언어를 전환하고 입력 초안 유지, 새로고침 후 언어 복원, 동의창·문진·내 정보·PDF·회원 탈퇴 문구와 모바일 줄바꿈을 확인합니다.

```powershell
node --test tests/i18n.test.mjs
$env:MEDICAL_TEST_BASE_URL='http://127.0.0.1:3080'
node --test tests-next/i18n-ui.test.mjs
```

선택 언어를 실제 AI에 전달하는 기능은 팀의 별도 백엔드 연동 범위입니다. 기존 상담 요청의 `locale`와 응답의 `ko/en/zh/vi/uz` 텍스트 지원은 유지합니다.
